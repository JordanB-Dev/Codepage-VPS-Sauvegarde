Règles de confidentialité

Dernière mise à jour : 14 novembre 2026

Usage de l'application

CodePage Sauvegardes est une application à usage strictement personnel, utilisée uniquement par son propriétaire.

Accès Google demandé

L'application demande uniquement l'accès https://www.googleapis.com/auth/drive.file. Cet accès lui permet de voir, créer, modifier et supprimer uniquement les fichiers qu'elle a elle-même créés. Elle n'accède à aucun autre fichier du Google Drive.

Données traitées

Les seules données traitées sont des fichiers de sauvegarde, chiffrés avant leur envoi. Aucune donnée personnelle n'est collectée, vendue, partagée avec des tiers ni utilisée à des fins publicitaires.

Politique des API Google

L'utilisation et le transfert des informations reçues des API Google par CodePage Sauvegardes respectent la Google API Services User Data Policy, y compris les exigences « Limited Use ».

Révocation de l'accès

L'accès peut être retiré à tout moment sur https://myaccount.google.com/permissions.

Contact

Pour toute question : contact@codepage.dev
